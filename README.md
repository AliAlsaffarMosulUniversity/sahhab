# سحّاب — مدير التنزيلات

تطبيق لتنزيل الملفات والفيديو بعدة اتصالات، مثل برنامج
Internet Download Manager

يعمل على الهاتف والحاسوب، ويُثبَّت كتطبيق مستقل.

من أعمال لوجيكال كود — الموصل.

---

## ماذا يفعل

- يقسم الملف إلى أجزاء، وينزّلها معاً لزيادة السرعة.
- عندما ينتهي جزء، يأخذ نصف أكبر جزء متبقٍّ، فلا يبقى اتصال فارغاً.
- إيقاف مؤقت واستئناف، حتى بعد إغلاق التطبيق.
- طابور تنزيلات، وحد للسرعة.
- تنزيل فيديو البث بصيغة:

  m3u8

- مستخرج روابط: تعطيه صفحة، فيعرض كل الفيديو والملفات فيها.
- مشغل داخلي للفيديو والصوت والصور.
- في الهاتف: شارك أي رابط من أي تطبيق إلى سحّاب مباشرة.

لا يدعم المنصات التي تحمي محتواها، مثل يوتيوب ونتفليكس وشاهد.

## محتوى المجلد

| الملف | وظيفته |
|---|---|
| index.html | التطبيق كاملاً |
| manifest.json | يجعل التطبيق قابلاً للتثبيت |
| sw.js | يجعل الواجهة تعمل بدون إنترنت |
| icons | أيقونات التطبيق |
| proxy/worker.js | خادم الوسيط، يُرفع إلى Cloudflare |

## الخطوة الثانية: خادم الوسيط (مجاني)

لماذا؟
أغلب المواقع تمنع التطبيقات من قراءة ملفاتها مباشرة.
الوسيط يجلب الملف ويمرره للتطبيق.
بدونه يعمل التطبيق فقط مع المواقع التي تسمح بذلك.

الخطوات:

1. افتح الموقع وسجّل حساباً مجانياً:

   https://dash.cloudflare.com

2. من القائمة اختر:

   Workers & Pages

   ثم:

   Create

   ثم:

   Create Worker

3. سمِّه:

   sahhab-proxy

   ثم اضغط:

   Deploy

4. اضغط:

   Edit code

   امسح الكود الموجود، والصق محتوى الملف:

   proxy/worker.js

   ثم اضغط:

   Deploy

5. انسخ رابط العامل، يكون بهذا الشكل:

   https://sahhab-proxy.اسمك.workers.dev

6. في التطبيق، افتح الإعدادات، والصق الرابط في خانة:

   عنوان خادم الوسيط

حماية الخادم (مستحسن):
حتى لا يستعمله غيرك، افتح إعدادات العامل:

Settings

ثم:

Variables and Secrets

أضف متغيراً سرياً اسمه:

KEY

واكتب له أي كلمة سر.
ثم اكتب الكلمة نفسها في التطبيق، في خانة مفتاح الوسيط.

الخطة المجانية تسمح بمئة ألف طلب يومياً، وهذا يكفي بكثير للاستعمال الشخصي.

## ملاحظات مهمة

- التنزيل يتوقف إذا أغلقت التطبيق أو نام الهاتف.
  عند فتحه مرة أخرى اضغط استئناف، فيكمل من حيث توقف.
- الملفات تُحفظ داخل التطبيق أولاً، ثم تنتقل إلى مجلد التنزيلات.
  احذفها من التطبيق بعد حفظها لتوفير المساحة.
- بعض الخوادم لا تسمح بالتقسيم.
  عندها ينزل الملف باتصال واحد، ويبدأ من جديد إذا انقطع.
